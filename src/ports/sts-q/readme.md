# sts-q's packages

| Package | Description | Availability |
| --- | --- | --- |
| [`ssqJson`](ssqJson/PORT.toml) | JSON parser and printer | Model-2 library |
| [`oberon`](oberon/readme.md) | `Kbd` terminal keyboard and mouse input | Unix model-2 library |

Both libraries are GPL-3.0, without the VOC runtime exception. Their source
repositories and imported revisions are listed in each package's `PORT.toml`.

The editor and utility modules from sts-q's `oberon` collection are in
[`src/examples/libraries/sts-q/editor`](../../examples/libraries/sts-q/editor/readme.md).
They are built with the example, not installed as libraries.
